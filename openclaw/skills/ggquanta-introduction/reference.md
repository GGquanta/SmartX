## 一、量子随机数芯片对比

| 产品指标 | 国光量子 | 友商 | 传统加密 |
|---|---|---|---|
| 量子加密 | 有 | 有 | 无 |
| 芯片化 | 已实现 | 在研（2024 年报随机数样机） | 无 |
| 小型化 | 约 0.7 cm³ | 1U 机箱（63×48×4 cm） | 无 |
| 集成化 | 可集成无人机、PC 等 | 难以小型化集成 | 无 |
| 速率 | 10 Gbps 以上 | 0.001–1 Gbps | 无 |
| 可靠性 | 抗电源纹波等侧信道攻击 | 易受侧信道控制 | 可被算力破解 |

**终端无线场景**：真空能量涨落随机数 + 抗量子算法；生成速率 ≥ 200 Mbps；支持 RedCap。

**抗量子算法**：ML-KEM、ML-DSA、SPHINCS。

## 二、离子阱监测仪

**原理**：真空紫外光电离源 → 痕量多组分电离 → 离子阱检测模组 + 极弱光检测；ppb 级在线连续监测。

**GIS 场景**：SF6 分解物、变压器冷却油局放气体；标样最低检出限 0.1–1 ppb。

**应用领域**

| 领域 | 示例 |
|---|---|
| 临床医疗 | POCT 生化、肿瘤标志物、血药监护（如利血平） |
| 环境保护 | 水质、土壤农残、空气污染、饮用水激素 |
| 食品安全 | 农残、添加剂、食源微生物鉴定分型 |
| 刑侦防化 | 毒品、爆炸物、战场毒剂、混合毒品 |
| 工业/电力 | GIS 气体、管道泄漏、局放检测 |

**中标**：国家级 ZF 1 项；省级（国网北京、中国电科院）1 项。

## 三、量子电磁传感

**能力**：非接触式电流/电磁信号；高精度、高灵敏度、高稳定性、体积小。

**场景**：主变及开关监测、特高压线路电流、配网故障定位、新能源并网点/汇流箱、铁芯剩磁、集电线路漏磁；新能源车电池、电缆、储能电站磁测量。

**中标**：工信部国家级 1 项；省级（国网北京、中国电科院）1 项。

## 四、单光子探测与雷达

| 类型 | 场景 |
|---|---|
| 测距雷达 | 卫星间测距、深空探测、工业毫米级测绘 |
| 极弱光通信 | 深海潜航器—水面平台、战场抗截获通信 |
| 无人机探测雷达 | 机场净空、边境、核心政务区；低空慢速小目标全天候探测 |
| 抗欺骗抗干扰雷达 | 雷达对抗环境、民航/军用导航抗干扰 |

**可鉴频单光子探测器（资料口径）**：波长 950–1650 nm；工作频率 1.25 GHz；探测效率 30%；暗计数率 < 1×10⁻⁵/gate；时间分辨率 ≤ 20 ps。

## 五、量子微气象站 / 雷达指标

| 雷达类型 | 主要指标 |
|---|---|
| 风场与颗粒物 | 探测距离 12 km+；距离分辨率 30 m；风速精度 0.5 m/s；范围 0–70 m/s；时间分辨率 1 s |
| 水汽 | 范围 3 km；浓度 ±10% |
| 碳监测 | 范围 3 km；精度 5 ppm |
| 噪声 | 定位三维误差 ≤ 1 m；测量 ±1.5 dB(A)；距离 3–500 m |

**产品型谱**：水汽监测雷达、碳监测雷达、甲烷监测雷达、灰霾风场检测雷达（监测距离可达 12 km）。

**价值**：10 km 范围高精度大气参数（风速、温度、气压、浓度、湿度）+ 局部气象模型辅助预测；服务变电站、光伏、风电场。

### 雷达产品线补充（product-intro 口径）

| 产品 | 探测距离 | 分辨率/精度 |
|---|---|---|
| 水汽/颗粒物雷达 | 水汽 ~3.2 km；颗粒物 ~15 km | 25 m；水汽混合比 ±10% |
| 碳监测雷达 | ~3 km | 30 m；柱浓度误差 ≤ 5 ppm |
| 测风雷达 | 30 m–20 km | 风速 ≤ 0.1 m/s；风向 ≤ 5° |

共性：全光纤结构、单光子/相干探测、差分脉冲、特定气体吸收线抑背景、近红外人眼安全。

## 七、光量子计算
